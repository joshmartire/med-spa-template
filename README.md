# Med Spa Website Template

A reusable, production-ready static website for med spas and medical aesthetics clinics, built by [Rank Boss](https://getrankboss.com) to the Rank Boss master website specification (technical SEO, local SEO, schema, accessibility, legal drafts).

It uses a clean clinical style built to earn trust: white and mist surfaces, deep navy text, one calm teal accent for actions, soft blush panels for warmth, and sentence-case Manrope headings. It keeps the Rank Boss panel layout from getrankboss.com, calmed down for a medical audience. Each clinic can swap in its own three colours.

Static HTML, CSS and JavaScript. No frameworks, no trackers and no third-party requests: fonts are self-hosted and every drawing is inline SVG generated by the build.

**Demo:** `rankboss-med-spa.pages.dev` (noindexed, with a "Website demo" banner). Sample business: **Peony Aesthetics**, Windsor, ON.

## What's on the home page

- **Hero:** the clinic's claim ("Natural results, medically led" by default), a sentence on who performs treatments, two buttons, the phone number and address, a large picture (the clinic's photo or a peony drawing) with a "Complimentary consultation" card, and a strip of the first four safety standards.
- **Your safety comes first:** six standards (licensed injectors, medical director oversight, consultation first, sterile single-use supplies, approved products, follow-up visit), set in config. They also appear on the treatments hub and in a "Your safety" card on every treatment page.
- **Three ways in:** injectables, skin, and laser and body as stacked colour sheets that slide over each other as you scroll, each listing its treatments with starting prices.
- **Treatment finder** (the live thing): tick what you want to change (lines, volume, lips, dull skin, texture, sun spots, hair, loose skin, stubborn fat) and how much downtime you can take; matching treatments appear with time, downtime and price, and the "Ask about these" button carries them into the booking form.
- **How a visit works:** talk, plan, treat, review, as four numbered steps.
- **First visit + the menu:** the free consultation beside the full starting-price list.
- Areas, a question per band (all answers visible), and the closing panel.

An opening animation (the peony blooms on white, the name rises) plays once per browser session, can be skipped with a tap or key, and is skipped for reduced motion.

## Folder layout

```
/                          published site (generated HTML, sitemap.xml, robots.txt, 404.html)
/assets/css/main.css       all styles (tokens at the top)
/assets/js/main.js         menu, dropdowns, reveals, opening animation, booking form
/assets/js/finder.js       the treatment finder
/assets/fonts/             Manrope (SIL Open Font License)
/assets/img/               favicons, logo, social image (generated by make_images.py)
/_build/                   generator, content and QA (NOT published)
  site.config.json         <- everything client-specific
  content_services.py      <- treatment copy
  content_cities.py        <- towns: local notes, rotated facts, how to get to the clinic
  pages.py                 <- home copy, FAQ, about, legal drafts
  art.py                   <- the drawings used until the clinic supplies photos
  build.py                 <- generator
  qa.py                    <- static checks (links, SEO, schema, word counts, contrast, regulated wording...)
/docs/                     new client setup, launch checklist, compliance notes
```

**Never hand-edit the generated HTML.** Change `_build/`, then rebuild.

## Build

```bash
pip install pillow fonttools brotli
python3 _build/build.py
python3 _build/qa.py
```
